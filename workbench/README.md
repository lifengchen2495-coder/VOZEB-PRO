# VOZEB 本地工作台

参考 VOZEB PRO 统一创作 Agent 做的单用户本地版：不需要数据库、登录、积分或后台，一条命令在自己电脑上启动，接入任意 OpenAI 兼容接口完成对话、图片和视频创作。

## 功能

- **一个输入框完成创作**：空白对话时输入框居中，并给出推荐提示词；开始对话后输入框贴底。底部单行工具条依次是创作类型（对话 / 图片 / 视频）、模型、生成参数和「优化」，点开才展开选项。
- **对话**：流式回复、多轮上下文、Markdown 渲染，可附图片让模型看图（需模型支持视觉）。
- **图片**：文生图（`/images/generations`），附参考图时走图片编辑（`/images/edits`）；可选尺寸、画质和 1–4 张，多张结果可切换查看和大图预览。
- **视频**：OpenAI 视频接口（`/videos` 创建、查询、下载），可附一张首帧参考图，可选时长和尺寸。
- **优化提示词**：用默认对话模型改写当前输入，结果回填到输入框继续编辑，不会自动发送。
- **引用继续创作**：结果卡片和右侧「当前对话素材」面板都可以把图片引用到输入框，作为下一轮的参考图。
- **按真实比例展示**：图片和视频卡片按媒体真实宽高等比缩放，生成中显示同比例占位。
- **本地保存**：会话、设置、参考图和生成的图片视频都保存在 `.data/` 目录；参考图在发送时才上传。刷新或重启后自动恢复，关闭页面不影响后台生成。
- **失败重试**：失败的结果原地「直接重试」，沿用原模型和参数，不新增消息；服务重启时已拿到上游任务 ID 的视频会继续查询，不会重复创建。
- **历史管理**：搜索、按今天 / 最近 7 天 / 更早分组、行内改名、单个删除和批量删除（连同媒体文件）。
- 浅色 / 深色主题跟随系统，适配手机宽度。

## 启动

需要 Node.js 20.9 或更高版本。

```bash
cd workbench
npm install
npm run dev        # 开发模式，打开 http://127.0.0.1:3100
# 或者
npm run local      # 构建后以生产模式运行，速度更快
```

首次打开会自动弹出「设置」：填写接口地址（例如 `https://api.openai.com/v1` 或你的中转地址）、API Key，以及对话、图片、视频各自可用的模型（每类可填多个，第一个为默认，创作时在输入框的「模型」入口切换）。也可以复制 `.env.example` 为 `.env.local` 预先填写，页面里保存的设置优先。

服务只监听 `127.0.0.1`，API Key 只保存在本机 `.data/settings.json`，不会返回给浏览器。

## 没有 Key 时先体验

```bash
npm run mock       # 在 3199 端口启动本地模拟上游
```

然后在设置里把接口地址填成 `http://127.0.0.1:3199/v1`，API Key 随便填，点「从接口读取模型列表」即可。模拟上游会返回假的文字、彩色测试图和 2 秒测试视频（视频需要本机装有 `ffmpeg`）。

## 目录

```
src/app/page.tsx               页面布局：空白首页、消息流、素材面板、轮询
src/app/components/            输入框、消息与结果卡片、历史侧栏、素材面板、设置
src/stores/workbench.ts        页面状态与操作（草稿、发送、重试、引用、优化）
src/app/api/                   本地接口（设置、会话、发送/重试、优化、上传、媒体）
src/lib/server/store.ts        JSON 文件存储与媒体落盘
src/lib/server/generation.ts   发送、后台任务、重试与重启恢复
src/lib/server/upstream.ts     通过 openai SDK 调用上游
scripts/mock-upstream.mjs      本地模拟上游
```

数据目录可用环境变量 `WORKBENCH_DATA_DIR` 修改。
