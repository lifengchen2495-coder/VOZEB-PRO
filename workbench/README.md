# 灵匠 AI 工作台

一个在自己电脑上运行的 AI 创作工作台：对话、出图、做视频都在一个页面完成。单用户使用，不需要数据库、登录或后台，接入任意 OpenAI 兼容接口即可。

## 功能

- **工作台框架**：顶部是品牌、全局搜索（⌘K / Ctrl+K）、「+」新建创作和任务提醒；下面一行模块标签切换总览、AI 创作、素材库、生成任务和模型设置。
- **总览**：问候与接口连接状态、AI 对话 / 图片生成 / 视频生成三个快捷入口、作品与任务统计、最近作品、最近对话和任务动态。
- **AI 创作**：左侧对话列表（搜索、按时间分组、行内改名、批量删除），中间对话区，右侧当前对话素材。空白对话时输入框居中并给出推荐提示词；底部单行工具条依次是创作类型、模型、生成参数和「优化」，点开才展开选项。
  - 对话：流式回复、多轮上下文、Markdown，可附图片让模型看图。
  - 图片：文生图（`/images/generations`），附参考图时走图片编辑（`/images/edits`）；可选尺寸、画质和 1–4 张。
  - 视频：OpenAI 视频接口（`/videos`），可附一张首帧参考图，可选时长和尺寸。
  - 结果按真实比例展示，可下载、引用到下一轮、复制提示词；失败的结果原地「直接重试」。
- **素材库**：所有生成的图片、视频和上传过的参考图，可按类型筛选、搜索提示词、排序，一键用作参考新建创作或跳回所在对话。
- **生成任务**：图片和视频任务列表，按进行中 / 已完成 / 失败筛选，显示模型、参数和耗时，失败任务可直接重试。
- **模型设置**：填写接口地址和 API Key，测试连接并读取模型列表，为对话、图片、视频分别配置多个模型（第一个为默认），可设置对话系统提示词。
- **本地保存**：对话、设置、参考图和生成的图片视频都保存在 `.data/` 目录；参考图在发送时才上传。关闭页面不影响后台生成，服务重启时已拿到上游任务 ID 的视频会继续查询，不会重复创建。
- 浅色 / 深色主题跟随系统，适配手机宽度。

## 启动

需要 Node.js 20.9 或更高版本。

```bash
cd workbench
npm install
npm run dev        # 开发模式，打开 http://127.0.0.1:3100
# 或者
npm run local      # 构建后以生产模式运行，速度更快
```

首次打开会提示还没有连接模型接口，进入「模型设置」填写接口地址（例如 `https://api.openai.com/v1` 或你的中转地址）和 API Key，点「测试连接并读取模型」后选好模型保存即可。也可以复制 `.env.example` 为 `.env.local` 预先填写，页面里保存的设置优先。

服务只监听 `127.0.0.1`，API Key 只保存在本机 `.data/settings.json`，不会返回给浏览器。

## 没有 Key 时先体验

```bash
npm run mock       # 在 3199 端口启动本地模拟上游
```

然后在「模型设置」里把接口地址填成 `http://127.0.0.1:3199/v1`，API Key 随便填，点「测试连接并读取模型」即可。模拟上游会返回假的文字、彩色测试图和 2 秒测试视频（视频需要本机装有 `ffmpeg`）。

## 目录

```
src/lib/brand.ts                     产品名称与标语
src/app/components/shell.tsx         顶部栏、模块标签、全局搜索快捷键
src/app/(workspace)/page.tsx         总览
src/app/(workspace)/studio/          AI 创作（对话列表、对话区、素材面板）
src/app/(workspace)/library/         素材库
src/app/(workspace)/tasks/           生成任务
src/app/(workspace)/settings/        模型设置
src/app/components/                  输入框、消息与结果卡片、搜索面板等
src/stores/workbench.ts              页面状态与操作（草稿、发送、重试、引用、优化）
src/app/api/                         本地接口（设置、会话、发送/重试、优化、上传、媒体、工作台汇总）
src/lib/server/store.ts              JSON 文件存储、媒体落盘与工作台汇总
src/lib/server/generation.ts         发送、后台任务、重试与重启恢复
src/lib/server/upstream.ts           通过 openai SDK 调用上游
scripts/mock-upstream.mjs            本地模拟上游
```

数据目录可用环境变量 `WORKBENCH_DATA_DIR` 修改。
