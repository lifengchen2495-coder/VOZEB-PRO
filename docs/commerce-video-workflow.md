# 电商视频流程生成

入口：电商创作 → 视频流程生成（`/commerce/video`）。

根据产品需求和当前启用的视频 Skill，生成制作路线、素材清单、阶段依赖、分段方案及提示词。适用于原创商品展示、对标视频换品、分镜图转视频等需求；不绑定某个视频模型或专用工作区。

## 使用前配置

1. 管理员在站内技能库导入或创建视频 Skill，启用它，并将使用范围设为“视频”。
2. 配置可用的文本逻辑模型及其渠道；可设为默认文本模型，也可在页面选择。

页面和 API 使用站内技能库。安装在开发者电脑上的 Codex Skill 不会自动出现在站内列表中。

## 操作步骤

1. 填写产品、卖点和视频目标，选择 15、30 或 60 秒，以及平台、人物安排和文案语言。
2. 勾选已有素材。此处仅声明素材状态，没有上传或分析真实图片、视频、分镜或音频。
3. 选择视频 Skill 和规划模型，生成流程。此操作只请求文本模型，按系统文本模型规则计费。
4. 查看阶段输入、输出和先后依赖，修改或复制提示词。分段时间连续闭合，每段不超过 15 秒；执行前还需匹配所选视频模型支持的时长。
5. 图片和视频阶段可以打开相应创作入口，提示词会预填；补齐真实素材并选择生成参数后再执行。文本、剪辑及人工步骤按页面说明完成。
6. 下载 Markdown 或 JSON 保存方案。当前页面没有草稿持久化，刷新或离开会丢失结果及编辑。

规划不会自动创建视频项目、启动图片或视频任务，也不会自动向 Omni 等固定流程写入数据。

## Skill 更新方式

每次生成都会读取后台当前启用的 Skill 正文。修改正文并保存后，下次生成即使用新规则；已生成的流程保留原结果，需要重新生成才会应用更新。页面的刷新按钮用于更新可选 Skill 列表。

本功能没有自动同步 GitHub。源仓库更新后，需要管理员将新内容更新到站内技能库。规划服务仅读取已保存的 `instructions`，不会自动访问 Skill 正文引用的 `references`、网页或脚本；必要的规则应一并整理到站内 Skill 正文。

## 请求与验证范围

API：`POST /api/commerce/video/workflow`。要求登录，校验视频 Skill 和文本模型是否启用，并验证返回流程的阶段依赖、素材状态及分段时间。

同一进程内对同用户、同请求、同 Skill 内容版本和同模型的并发请求合并，成功结果短暂缓存。缓存最长 10 分钟，不提供跨实例或重启后的去重保证。失败重试及缓存失效后的实际模型请求使用新的计费身份；无效响应按实际消费流水走退款路径。

自动测试使用模拟模型响应，覆盖协议、路由、重试及页面交互。上线前仍需使用已配置的真实文本渠道验证模型输出质量。
