# 带货短剧人物图生成

“人物需求与素材”原先只生成文字清单，人物图必须手动上传，用户没有定妆照时无法进入分镜步骤。

新增每个角色的“生成人物图”按钮，使用当前选中的人物与九宫格生图模型，根据角色性别、年龄和稳定外观生成单人全身定妆照。生图复用现有持久化图片任务、积分结算和 Worker。成功后校验图片归属与服务器存储，自动加入人物参考素材并绑定对应角色；原剧本保留，受人物变化影响的后续分镜失效。已有图片可以手动上传和绑定。

页面显示生成状态、失败原因与可打开的图片预览。刷新或离开页面后重新读取可恢复任务并完成绑定。网络中断保留原请求号，“继续提交”复用同一次请求；未确认提交可检查后撤销，有已创建任务时不直接撤销。没有失败后的自动重试。生成失败保留旧绑定，重新生成成功后才切换；参考图仍遵守每类最多 8 张限制。

服务端在任务提交锁内核对角色、项目版本、请求号、尝试次数、提示词、模型和参考素材，拒绝伪造或已撤销的提交；迟到结果不能写回另一次请求。生成期间阻止项目修改和其他生成步骤；删除素材时清理对应绑定及图片状态。

新增状态与服务回归覆盖：正常提交、模型选择、自动绑定与持久化读取、幂等提交、撤销后迟到请求、其他用户和角色的结果隔离、失败保留旧图、素材删除，以及请求期间的项目锁定。真实模型及上线结果在完成验收后补充。
