# VOZEB PRO 功能总览

VOZEB PRO 把创作规划、图片与视频生成、画布、短剧生产、素材管理和商业运营放在同一套应用中。普通用户主要表达目标、受众和约束，Agent 负责形成专业方案并选择真实可用的模型能力。

## 五阶段创作闭环

### 1. 创作简报

Agent 会整理目标、受众、使用场景、核心信息、内容约束和参考素材策略。信息足够时直接合理补全，不要求用户先填写大型参数表单。

### 2. 灵感与视觉方向

系统在内部形成推荐方向，包含风格、构图或镜头、色彩、光线、视觉关键词和避免事项。这些规划数据用于约束后续任务，不作为冗长消息展示给用户。

### 3. 整套物料规划

Canvas Agent 可以在内部规划文本、图片、视频和音频之间的依赖关系，并保留继续派生配套物料所需的上下文。对话只显示用户输入、必要的自然确认、简洁完成提示和真实生成结果。

### 4. 一致性生成

真实任务继承同一份内部简报、视觉方向、参考素材策略和上游依赖摘要。智能规划开启时由 Agent 决定模型与参数；用户手动选择模型并给出明确提示词时保留其选择，但仍经过 Skill、能力、参考素材和计费校验。模型理由和平台提示词不显示或持久化到生成型对话。

### 5. 自动视觉复盘

存在可用带图文本模型时，图片结果可以在内部进行结构化视觉检查。复盘详情不写入生成型对话，也不会因为复盘模型不可用而阻塞已经成功的生成结果。

## 统一创作 Agent

图片、视频、音频和普通文本问答统一进入 `/create` 会话；`/image` 与 `/video` 只作为兼容入口重定向到 `/create`，不再维护独立工作台数据和交互。

### 图片创作

- 文生图、图生图和参考图编辑。
- 多结果生成、记录恢复、标题重命名、选择删除和失败重试。
- 智能规划开启时自动选择逻辑模型、画幅、质量和数量；关闭时要求用户选择模型。
- 手动模型与准确提示词可以直接执行，但仍必须通过 Skill 和能力校验。

### 视频创作

- 文生视频、图生视频和多类型参考素材。
- 比例、清晰度、时长、声音与水印等真实参数控制。
- 异步任务轮询、刷新恢复、历史记录与结果删除。
- 参考图存在时强调首帧、主体、服装、产品和构图一致性。

### 画布

- 文本、图片、视频、音频、创作简报、品牌规范和生成任务节点。
- 拖拽、缩放、连线、小地图、框选、多选、撤销重做和导入导出。
- Canvas Agent 可读取当前画布，规划多物料依赖并把结果回填为节点和连线。
- 任务支持依赖执行、暂停、恢复、取消、失败重试和刷新恢复。

### 短剧生产线

- 剧本分析、角色与场景、分镜、镜头视频、配音和字幕。
- FFmpeg 整集合成、中文字幕烧录、任务取消、预览和下载。
- 真实视频、音频渠道和生产镜像仍需按部署环境完成验收。

### 电商视频复刻

- `/remake` 是独立的复刻项目入口，工作区分为“来源分析”“十二宫格重绘”“生产内容”三个阶段。
- 来源分析会让视频理解模型完整观看来源视频，保留视频原语言的完整口播原文，提取原视频音频，并产出 48 个编号分析单元及对应抽帧。每个单元记录时间范围、字幕、卖点、镜头类型、画面描述、人物占比和人脸状态；48 个单元按 `1-12`、`13-24`、`25-36`、`37-48` 合成为 4 张 `3 × 4` 十二宫格，同时把原文案顺序映射为 16 个三帧语义区间。编号单元是固定分析结构，不等同于 48 个唯一切镜点。
- 十二宫格重绘固定按来源十二宫格、可选人物图、背景图的顺序提供生图参考；人物补充图不参与生图任务。服务端读取参考素材和 4 张重绘结果的真实像素后再规划生产内容。四组各生成一张 `9:16`、`3 × 4` 的十二宫格；商品身份、动作、构图、景别和镜头顺序以该组来源十二宫格为准。
- 生产阶段先生成原文案顺序检查报告。有口播时必须选择女性或男性配音，并使用提取音频作为音色参考；原文案为 `不需要人物口播` 时，16 个区间保持为空，视频提示词只输出分镜描述，不包含口播、配音、声音段或音频引用。两种分支都会生成 4 条各 15 秒的 Seedance 视频提示词，每条覆盖一组 12 个连续画面及 4 个三帧语义区间，但当前不在该工作区内直接生成最终 4 条视频。
- 完整 ZIP 生产包包含来源视频、48 张抽帧、可选人物图及人物补充图、背景图、有口播时的原视频音频、4 张来源十二宫格、4 张重绘十二宫格及对应 `@产品图` 引用副本、原文案、文案报告、分析 Markdown、时间点、结构化 JSON、生图/Seedance 提示词、素材绑定和导出 Manifest。导出前会做完整性预检，任一必需媒体缺失或下载失败都会中止整个 ZIP，不生成残缺生产包。
- 项目、阶段和生成任务支持刷新恢复、请求幂等、版本冲突保护、下游失效重算、失败退款与持久媒体登记。同一来源视频重新分析时保留用户已经校对的原文案，替换来源视频时清空旧原文案并使旧分析、重绘和提示词失效。这里的“支持”指仓库代码与自动化契约，不代表真实模型渠道已经完成生产验收。

对照证据以飞书 Base 的可观察字段与产物为准：当前 live Base 共 26 个字段且 Base Workflow 数量为 `0`，其中没有独立“产品图”字段。已对飞书 `37-48 生图` 配置提示词完成逐字校验；Base 之外的自动化模型参数和其余不可见编排仍无法从表结构推断。完成真实模型小批量质量、费用和稳定性验收前，本功能仅可视为 `ready_for_prototype`，不能标记为 `ready_for_batch`。

## 模型与任务执行

- 管理员配置 OpenAI 兼容渠道、真实模型和能力标签。
- 文本、图片、视频、音频使用稳定的逻辑模型名称，后台决定实际渠道与优先级。
- 渠道支持模型目录读取、超时、错误脱敏和保存凭据复用；管理员在统一 Agent、Canvas 或短剧入口通过真实业务请求验证能力。
- 生成任务统一记录状态、积分、耗时、入口、模型和结果地址。
- 规划、生成和复盘由服务端计费，刷新或 SSE 重放不会重复创建任务或扣费；上游未明确失败时不会自动重复调用创建接口。

## 数据与素材

- PostgreSQL 保存用户、创作会话、Agent Run、Canvas、素材库、短剧项目、配置、任务、积分、订单和审计数据。
- 图片、视频和音频按媒体登记选择服务器 `VOZEB_PRO_DATA_DIR` 或 S3 兼容对象存储，业务表不保存 base64 或临时签名地址。
- 临时参考素材默认 24 小时过期；长期上传、生成结果和短剧成片由管理员明确删除。
- 后台“本地媒体”支持分类、预览、期限检测、单删、批量删除和过期清理。
- 后台“外部存储”支持 S3 兼容配置、连接检测、对象管理和已有本地媒体分批迁移。

## 商业运营

- 用户、角色、状态、积分和套餐权益管理。
- 每日免费积分、CDK、商品、订单、支付渠道、退款、财务流水和对账。
- 公告、提示词、模型渠道、Agent Skills、本地/外部媒体、业务备份和邮件配置。
- 模型、支付和 SMTP 密钥由服务端保护。

## 平台、数据与安全能力

- **数据库**：默认 PostgreSQL 16；账号、Session、配置、创作会话、消息、稳定资产、Canvas、素材、短剧、任务、积分、订单、支付和审计数据均在服务端保存。文件 Provider 仅作为项目既有单机回退。
- **服务端分页**：长会话默认加载最新消息并可向前加载；用户、订单、积分、提示词、CDK、生成记录和管理列表使用服务端分页或定向查询。
- **模型路由**：真实渠道与逻辑模型分离，支持能力标签、默认模型、优先级、候选渠道、可用性检测、错误脱敏和协议级隔离适配。
- **任务与计费**：创建请求幂等、同用户/类型并发约束、积分预扣、终态结算、失败退款、刷新恢复、明确失败后用户重试；查询超时不会重新创建上游任务。
- **媒体**：上传和生成文件按日期时间与 UUID 命名，同时登记原文件名、用户、来源、类型、会话/Run/任务/项目关联；页面使用 WebP 预览，下载返回原文件。
- **存储切换**：关闭外部存储时新文件只写服务器本地；开启时新文件只写 S3 兼容对象存储，本地不保留新持久副本；历史媒体按自身 Provider 读取。
- **媒体安全**：用户读取校验归属，上游引用使用短期签名 URL，删除前检查创作会话、素材、Canvas、短剧和生成记录引用。
- **账户安全**：密码哈希、Session Cookie、邮箱验证码失败限制、管理员权限、API 请求大小限制、代理跳数配置、敏感错误脱敏和审计日志。
- **个人权利**：用户可导出自己的业务数据并提交/撤回注销申请；正式删除和法定保留仍由运营制度与人工审核决定。
- **备份边界**：后台业务导入导出不包含凭据和媒体原文件；生产恢复必须同时覆盖 PostgreSQL、本地媒体目录或对象存储。
- **部署**：提供源码开发、标准 Compose、源码构建 Compose、宝塔 PostgreSQL、外部 PostgreSQL、低内存和 Render 配置；主应用与文档站提供 amd64/arm64 GHCR 工作流。

页面对应截图和逐页说明见[页面功能图册](/docs/overview/page-gallery)，目录与请求链路见[项目结构与流程](/docs/overview/project-structure)，上线前仍需验证的事项见[待测试](/docs/progress/pending-test)。

## 当前限制

- 视频视觉复盘在缺少可信封面或关键帧时只会标记为不可用，不会伪装成真实画面检查。
- 电商视频复刻已对飞书 `37-48 生图` 配置提示词完成逐字校验；其余表外自动化的模型参数和不可见编排仍不可验证，真实模型的 `1 SKU × 3 次` 重复运行和 `3～5` 条小批量结果尚待验收。
- Docker 静态资源路径、服务器媒体数据卷、真实支付退款和完整 Linux 部署仍需按待测试清单验收。
- 不支持抓取或复制未经授权的第三方图库、字体、图标和品牌素材。
