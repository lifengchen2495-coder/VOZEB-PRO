# 汇风 Omni Flash／Omni 1.1 接入

核对日期：2026-09-08。接口来源：[汇风 API 文档](https://huifengai.com/apidoc)。模型名称及参数以该站文档为准；文档没有将 Omni Flash 或 Omni 1.1 标注为 Google 模型。

在后台「模型渠道 → 接入新渠道」选择「汇风 Omni」，配置汇风 API Key。默认地址为 `https://api.lk888.ai`，鉴权为 `Authorization: Bearer <API_KEY>`。密钥仅保存在既有服务端渠道配置中，不写入源码或本文件。

用户已明确选择 Omni Flash／Omni 1.1，新建渠道仅加入以下两个型号。视频生成时由用户选择具体型号。

| 模型 ID | 用途 | 参考素材 | 输出限制 |
| --- | --- | --- | --- |
| `omni_flash-10s` | 文生视频、多图参考生视频 | 最多 7 张图片，无参考视频 | 固定 10 秒、720P；16:9 或 9:16 |
| `omni-1.1` | 文生视频、首帧生视频 | 可选 1 张首帧图，无参考视频 | 3–10 秒；720P、1080P 或 4K；16:9 或 9:16 |

Omni Flash 的上游渠道可能只能接收 1 张或 6 张参考图。应用不会自动删除参考图或更换模型；渠道拒绝后保留失败信息，由用户调整素材。

这两个型号不接收原视频，不能直接锁定原片动作。两个 Omni 复刻流程按用户要求保留原视频局部编辑方法论，现改为准备素材包、外部手动生成、回传合并，不自动提交视频任务，也不改成关键帧图生路线。上述渠道能力继续供普通视频工作台使用。

视频提交前会校验参考图数量、图片角色、时长和清晰度。本地受控参考素材在提交汇风前签发 90 分钟读取链接。

这里接入的是视频生成接口。全品类流程已停用旧自动视频分析入口，不调用固定豆包分析；用户复制分析指令和原片到外部工具，再导入分析结果。准备素材默认在本地整理提示词，不依赖 API Key；只有明确选择文本模型并点击可选 AI 优化时才调用该模型。

## 手动生成流程（2026-09-09）

- 服装复刻：上传原视频及服装图，填写替换要求和音频策略，准备片段后下载手动素材包。
- 全品类复刻：上传原视频，复制分析指令，导入外部返回的 `summary`／`segments` 分析 JSON，再准备片段与提示词。支持 Markdown 代码块及包含完整逐段 `prompt`／`promptZh` 的结果，也可单独导入 `materialAnalysis`／`plan`／`segments` 提示词计划。
- 素材包在尚未生成任何视频时即可下载，包含实际参考图、按音频策略处理过的源片段、逐段中英文提示词、生成清单和操作说明。原片提供动作与镜头，参考图仅定义对应的替换对象。
- 在外部工具按片段编号生成，逐段上传完整结果后合并；视频画面时长须覆盖对应源片段，超出部分在合并时截取。静音段在切片时移除音频，合并时也不会加入声音；保留原声的段落在合并时使用原片音轨。
- 回传校验项目归属、片段、当前素材及提示词、实际视频轨时长。服装结果作为用户永久素材保存；全品类上传先暂存 24 小时，采用后永久化。页面保留待保存记录，网络中断后可重试采用，无需重复上传。
- 新的 Omni 自动视频提交及全品类旧自动分析返回停用提示；已有视频任务仍可查询、取消或解除。未配置视频渠道也能准备、下载、回传和合并。

## 请求与状态

创建：`POST /v1/media/generate`。

```json
{
  "model": "omni_flash-10s",
  "prompt": "模特穿着参考图中的服装，自然转身展示细节",
  "params": {
    "images": ["https://example.com/outfit.png"],
    "aspect_ratio": "9:16"
  }
}
```

Omni Flash 固定 10 秒、720P，不发送额外时长或清晰度字段。Omni 1.1 则在 `params` 中增加字符串 `duration`（例如 `"5"`）及 `resolution`（`"720P"`／`"1080P"`／`"4K"`），最多提供 1 张首帧图。本站计费元数据经服务端签名传至内部代理，不混进供应商请求。

创建响应的任务 ID 位于 `data.task_id`，可能是整数。查询为 `GET /v1/media/status?task_id=<ID>`。只在 `is_final === true` 时判定终态，成功需 `state === "success"` 且有 `result_url`，失败为 `state === "failed"`。中文 `status` 只用于展示。

任务沿用系统持久化、归属校验、积分幂等和退款机制；未知创建结果保留原请求供检查，不自动重新创建。后台视频查询每 10 秒一次，自动查询窗口为 75 分钟，超出窗口保留原任务供人工检查。此窗口不延长单次 HTTP 请求超时。

本接入不修改站点全局默认模型。两款型号之间不自动切换，失败时保留原任务及错误信息。
