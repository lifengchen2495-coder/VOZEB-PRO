# 视频提示词生成指令

需要人物或场景参考图的制作流程，提供生成视频提示词所用的指令全文。用户可以修改镜头、节奏、风格和声音要求，保存后按新指令重新生成视频提示词。

| 功能 | 编辑入口 | 作用范围 |
| --- | --- | --- |
| 15 秒换品换人 | 生成内容中的视频提示词生成指令 | 当前分镜组 |
| 1 分钟换品换人（含已有 `remake60` 项目） | 生成内容中各组的视频提示词生成指令 | 修改的分镜组 |
| 1 分钟只换人物 | 生成内容中各组的视频提示词生成指令 | 修改的分镜组 |
| Omni 全品类复刻 | 片段计划中的视频提示词生成指令 | 全部片段的中英文提示词与计划 |
| 带货短剧 | 视频提示词环节的生成指令 | 全部视频提示词片段 |
| 短剧工作台 | 分镜与生成页面的视频提示词生成指令 | 当前集的镜头视频提示词 |

指令与项目一起保存。旧项目自动使用各功能原有默认指令；恢复默认不会修改来源模板。生成前先保存指令，保存失败时不启动新的生成请求。每份自定义指令最多 50,000 字，模型接收修改后的全文，并继续遵守对应流程的结构、素材和时长校验。

修改指令保留上传素材、来源分析与已生成的分镜图，使受影响的视频提示词和后续视频失效。已运行的任务按各流程现有任务锁或输入版本校验处理，避免旧结果覆盖新配置。修改最终的视频提示词仍可使用各功能原有的编辑入口。

复刻系列与 Omni 的素材包同时导出有效生成指令；带货短剧沿用其生成指令文本导出。短剧工作台的指令随项目保存。
