# 带货短剧裂变接入

电商工作台中的「带货短剧裂变」进入 `/bangbang`。支持只上传产品图的「产品原创」和使用对标视频的「对标裂变」。棒棒脚本与棒棒生图共用一个项目，素材、完整中间文本、分镜与人工审核结果保存在服务端，可离开页面后继续。

## 使用流程

1. 新建项目，默认「产品原创」。只上传至少一张产品图即可开始，产品名称、外观、已确认卖点、价格和创作要求可补充。模型识别可见外观并原创剧情，不编造未提供的参数、功效、价格或优惠。目标时长支持 15–300 秒，默认 120 秒；视频提示词单段上限支持 5–30 秒，默认 30 秒。
2. 产品原创直接进入创作方向，再生成完整剧本。可使用「根据产品生成剧本」自动生成方向、采用首个推荐方向并写出剧本，停在剧本供查看和编辑；也可单独生成方向后自行选择。此模式共 9 个环节，不需要视频、字幕、拆帧、百炼转写或视频分析模型。
3. 选择「对标裂变」时，上传对标视频，按顺序完成语音转文字、完整视频理解、流量逻辑分析、关键画面拆帧和裂变方向，再生成剧本。可使用「连续完成视频分析」，流程会停在方向选择。此模式保留原有 13 个环节。
4. 生成人物需求，给对应角色绑定人物参考图，生成分镜规划表。已有规划可在「分镜规划表」环节粘贴并保存，再运行该环节转换成结构化分镜；此转换需要模型调用。生成剧本不要求人物图，后续固定人物形象的生图环节才需要绑定。
5. 逐组展开九格分镜、优化生图提示词。每组固定 9 帧，组数根据剧情与时长规划。
6. 每次生成一张九宫格，人工确认后才能生成下一张。连续同场景引用本场景首张九宫格；切换场景时引用上一场景末张和匹配的场景参考图。离开后返回同名场景会重新建立首图锚点。
7. 全部九宫格通过后生成视频提示词，并导出生产素材 ZIP。视频提示词按顺序覆盖全部分镜，同场景最多合并两组，且不超过所设单段时长。本入口交付九宫格和提示词，实际视频生成由后续制作环节完成。

切换创作模式会清除之前的生成结果；产品图和已上传的对标视频可保留，产品原创不会使用保留的视频或其分析结果。修改影响剧情或素材的上游内容，会使相关下游结果失效。重做某张九宫格会清除该张及其后续图片审核和视频提示词。生图提交结果不确定时可检查状态、复用原请求继续提交，或安全撤销尚未创建任务的请求。

「导出文本包」可在中途保存完整过程、项目 JSON、分镜 CSV/JSON 和已有提示词；「导出生产素材包」要求全部九宫格已确认且视频提示词完整，另外包含生产图片与参考素材。

在「视频提示词」环节可查看实际使用的生成指令全文，编辑镜头语言、节奏、声音等要求，保存到当前项目；「保存并生成／重新生成」会先保存新指令，再按它生成各段视频提示词。保存修改会使旧视频提示词失效，保留分镜与已确认的九宫格。未完成生图也可提前编辑，实际生成仍需逐张确认全部九宫格。可恢复默认指令；用户自定义指令在切换创作模式时保留，默认指令按当前模式加载。分镜覆盖顺序、单段时长和六段输出格式继续由项目规则保证。导出包附带「视频提示词生成指令.txt」。

## 服务端配置

- 复用平台模型渠道、逻辑模型、积分计费和媒体存储。项目可分别选择视频分析、剧本与提示词、生图模型；未选择时使用平台默认或服务端适用候选。
- 产品原创使用项目选择的剧本与提示词模型，未选择时从平台默认文本模型解析候选，要求支持图片理解；不依赖固定的豆包视频模型。
- 对标裂变的完整视频分析使用上游模型 `doubao-seed-2-0-pro-260215`，渠道需支持火山方舟兼容的 Files 和 Responses 接口。单纯支持图片理解的文本渠道不能代替完整视频输入。
- 剧本与生产提示词阶段可能包含人物、产品或九宫格图片，选择支持相应视觉输入的模型。生图模型需支持参考图编辑、`9:16` 和 `2K`。
- 自动语音转写使用百炼 `paraformer-v2`，从服务进程环境读取 `DASHSCOPE_API_KEY`，兼容 `DASHSCOPE_KEY`。未配置时可手动导入字幕。百炼费用由所配置的百炼账户承担，未新增独立的平台 ASR 积分费率。
- 服务器需提供 `ffmpeg` 和 `ffprobe`；可用 `FFMPEG_PATH`、`FFPROBE_PATH` 指定路径。对标视频最大 200 MB、最长 600 秒；完整视频分析会全程转码，分析输入上限 24 MB，不截取片段冒充完整视频。音轨转写上传上限 25 MB。
- 支持既有 JSON 文件与 Postgres 存储模式；Postgres 使用独立 `bangbang_projects` 表，由项目现有 schema 初始化流程创建。

## 提示词来源

来源为 [飞书接入教程](https://ov09gvv1wfr.feishu.cn/wiki/V1iFwBoYCic1T1ksCmac5Yvynpf) 的两份 Skill 附件，以及本机已有适配版。`bangbang-prompts.source.json` 记录原始附件及各模板的 SHA-256、原版与适配版差异。原附件中未提供正文的隐藏 Skill 使用明确标记的平台补充规则；案例人物与商品已改为项目输入，未将补充内容冒称为原版。

产品原创的创作方向与完整剧本使用平台新增提示词，按产品外观、确认的事实和创作要求设计钩子、冲突、转折、产品介入与结尾，不冒充对标视频分析结果。
